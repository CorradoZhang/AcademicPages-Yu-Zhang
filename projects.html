Advanced Learning-based Robotic Arm Control

Type: Robotics System Project

Code: https://github.com/CorradoZhang/Advanced-Learning-Based-Robotic-Arm-Control

This project focuses on robotic arm grasping in MuJoCo, covering environment design, reinforcement learning training, and hierarchical reinforcement learning.

Project Highlights

  • Built a Gymnasium environment for robotic arm grasping using MuJoCo.
  • Applied reinforcement learning to train the robotic arm for grasping tasks.
  • Extended the project with hierarchical reinforcement learning.

Technologies: Python · MuJoCo · Gymnasium · Reinforcement Learning · Hierarchical Reinforcement Learning
